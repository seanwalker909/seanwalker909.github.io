Data flows worth calling out

Media pipeline. Prowlarr propagates indexer definitions to Jackett; Sonarr/Lidarr discover and request content; qBittorrent-nox downloads; Jellyfin transcodes/serves, with WidevineCdm present for DRM playback paths. All daemons run as systemd services with /opt-based installs — a deliberately different deployment pattern from the containerized apps, chosen for the *arr suite's native ARM64 packages.

Local AI. Open WebUI (8081) serves the chat interface and points at an OpenAI-compatible backend — the LM Studio local-model server running on the MacBook Pro (172.16.0.244:1234, M2 / 32 GB) over the LAN — rather than a model server on the Pi itself; searxng-mcp exposes the local SearXNG instance as an MCP search tool; LibreTranslate (5001) provides offline translation. Together these form a self-contained AI layer with no per-query egress — the same integration pattern (MCP + OpenAI-compatible APIs) used in the agent stack.

Agents & automation. n8n (5678, runners enabled, webhook-secured behind TLS) runs scheduled and event-driven workflows. The Hermes Agent runtime adds MCP servers (Grafana, n8n, Yahoo Finance, Yuvomi, iTerm) as tool surfaces, cron-driven jobs, and a dashboard — turning the platform into something an agent can operate, not just host.

Photos. Immich is a three-container service (server + Postgres with pgvector/vectorchord + ML worker) plus Valkey: person recognition and smart search run locally against vector indexes — a real ML-serving topology on 8 GB of RAM.

Network topology

  • Edge: NPM terminates TLS on 443 (80 → redirect), publishes host definitions for each app; DuckDNS resolves the public name to the LAN IP.
  • Internal: each service group gets its own Docker bridge (br-*); shared services (Immich stack) share a group network; web-proxy is an external network the proxied apps join. Internal-only services (Immich postgres, Valkey, FlareSolverr) are loopback- or bridge-bound and never published to the LAN.
  • Host: systemd daemons bind to 0.0.0.0 only where LAN access is intended (Jellyfin, qBittorrent webui on the LAN IP), otherwise loopback.

Observability spine (end-to-end, live)

prometheus-node-exporter (9100, active) → Prometheus (prom/prometheus, :9090, restart: unless-stopped, TSDB persisted on named volume prometheus-data, config at ~/prometheus/prometheus.yml — 15 s scrape of 172.16.0.229:9100, target node_exporter up) → Grafana (3000, official Prometheus datasource). The full metrics pipeline is running and exposed at prometheus.b0g0.duckdns.org. Disk health via smartmontools (active). This is the same Prometheus → Grafana pattern used professionally (see background: Datadog/Prometheus/Grafana at Dolby and VictoriaMetrics at AppOmni) — here, owned end to end on nvm3.
