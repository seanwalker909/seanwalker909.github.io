This wiki is a living, browsable record of a real, running system — not a slide deck. Every service below is live on the host (nvm3, a Raspberry Pi 5), verifiable by port, process, or dashboard. The system has served as a personal production platform since mid-2026: media pipeline, photo archive, local AI, automation, security, and the observability to prove it all works.

The platform in one paragraph

A Raspberry Pi 5 (8 GB RAM, 1 TB NVMe HAT) running Debian 13 on kernel 6.18, provisioned via RPi-Imager, acting as the DNS, reverse proxy, and service host for a home network. On it: a seven-daemon media pipeline (Jellyfin + the *arr suite + qBittorrent), a self-hosted Immich photo stack with ML, a local AI layer (Open WebUI + SearXNG + LibreTranslate + a Hermes OpenAI-compatible endpoint), an n8n automation engine, Vaultwarden, Pi-hole, and a Prometheus/Grafana observability stack — fronted by Nginx Proxy Manager with automated TLS, and backed by nightly encrypted-adjacent credential backups. This is the same kind of work as the production platforms I have operated professionally: containers, GitOps-style declarative config, observability, and security hygiene — at a scale a single engineer owns end to end.
