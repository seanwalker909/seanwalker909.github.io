Local AI & Agent Automation

A self-contained AI layer on the Pi: a chat UI, a local search backend exposed as MCP, offline translation, an n8n automation engine, and an autonomous agent runtime (Hermes) whose tools span the rest of the platform.

Stack

Component Role Access
Open WebUI LLM web interface (port 8081) container, proxied via NPM
Backend endpoint OpenAI-compatible API — LM Studio on the MacBook Pro M2 (2023), 32 GB, always-on (172.16.0.244:1234). Chain: Open WebUI (nvm3) → Hermes (nvm3) → LM Studio (Mac), over the LAN config
SearXNG + searxng-mcp Private metasearch, exposed to agents as an MCP tool (port 8889) container
LibreTranslate Offline machine translation API (port 5001) container
n8n 2.37.10 Workflow automation: webhooks, schedules, runners enabled (N8N_RUNNERS_ENABLED), webhook URL behind TLS, proxy-hops aware container, port 5678
FlareSolverr Anti-bot solving for web-scraping steps (loopback-only, 8191) container
Hermes Agent Agent runtime: multi-platform gateway, MCP tool integration (Grafana, n8n, Yahoo Finance, Yuvomi, iTerm), cron jobs, skills, memory host process

What this demonstrates

  • MCP in production use. SearXNG-as-MCP and the Grafana/n8n/finance MCP servers mean the agent layer talks to real infrastructure over a standard tool protocol — the same integration pattern now common in enterprise AI stacks (LangChain/LangGraph/MCP), built and operated hands-on, not just read about.
  • Local-first AI. Search, translation, and LLM inference run on the local network with no per-query egress — the model server (LM Studio) sits on the MacBook Pro, served to the Pi over the LAN. A privacy posture that mirrors the "data residency" work done at AppOmni (Private Service Connect, PgBouncer).
  • Automation as a platform. n8n runners + webhooks + an agent that can drive the platform (read Grafana metrics, execute workflows, manage calendars) is the "agentic ops" pattern emerging in SRE: the platform is both the object of automation and the executor of it.
  • Agent-operated day-2 ops. This wiki was researched by an agent with live access to systemctl, docker ps, and Prometheus — the same tooling an on-call engineer uses. The stack is instrumented well enough that software can operate it.

Status (2026-10-02)

Open WebUI, searxng-mcp, n8n, LibreTranslate, FlareSolverr all up (33+ h at capture, healthy where healthchecks exist). The live local-model backend at capture is LM Studio on the MacBook Pro (172.16.0.244:1234), reachable over the LAN as the OpenAI-compatible endpoint above.
