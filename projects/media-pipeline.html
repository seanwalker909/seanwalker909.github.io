Media Pipeline

A complete, self-hosted media platform on one Raspberry Pi 5: discovery → download → library management → streaming, with a native-ARM64 daemon layer and a containerized edge.

Components

Component Role Deployment
Jellyfin 10.11.11 Streaming server (web + mobile clients) systemd, port 8096
WidevineCdm DRM content playback support /opt/WidevineCdm
Sonarr TV series: discovery, quality management, download requests systemd, /opt/Sonarr
Lidarr Music: artist/album management systemd, /opt/Lidarr
Prowlarr Indexer propagation to Jackett/*arr systemd, /opt/Prowlarr
Jackett Indexer API bridge (port 9117) systemd, /opt/Jackett
qBittorrent-nox Headless torrent engine (webui 62978, LAN-bound) systemd

The flow

indexers ──▶ Prowlarr ──propagate──▶ Jackett
                                        │
        Sonarr / Lidarr ──search──▶ Jackett ──requests──▶ qBittorrent
             │                                                        │
             └──── quality rules, upgrades, renames ◀── completion ──┘
                                        │
                                        ▼
                                  Jellyfin (stream, transcode, DRM via WidevineCdm)

Engineering notes

  • Two deployment patterns, deliberately. The *arr suite runs as native systemd daemons (official ARM64 packages), while the edge/adjacent services are containerized. Choosing the right packaging model per workload — rather than "everything in Docker" or "nothing in Docker" — is a real production decision.
  • Resource discipline on ARM: transcode-heavy workloads on 8 GB RAM mean the stack is tuned for the hardware (hardware-accelerated paths where available, sensible defaults), the same cost/footprint thinking as cloud right-sizing work.
  • Single-point ownership: indexer config, quality profiles, naming schemes, and client access are all managed by one person with full root on the box.

Status (2026-10-02)

All six daemons active (Sonarr, Lidarr, Prowlarr, Jackett, qBittorrent, Jellyfin). Radarr not present in the current set (movies not in use).
