The pipeline (exporter → TSDB → Grafana) is end-to-end live and matches the production observability stacks used professionally — Prometheus/Grafana/Loki at Dolby, VictoriaMetrics at AppOmni — scaled to one host.

Backup strategy (the strongest ops artifact on the box)

Vaultwarden — the most security-critical service — has a fully scripted, encrypted, offsite nightly backup (/usr/local/bin/vaultwarden-backup.sh, cron 0 0 * * *):

  1. set -euo pipefail — fail loud, no partial state.
  2. Stop the container (consistent snapshot), zip the data dir.
  3. AES-256-CBC + PBKDF2 encryption via openssl; key stored root-only (chmod 600).
  4. rsync over SSH to a second host (172.16.0.118) — off-box, off-device.
  5. Bring the service back up; plaintext archive deleted after encryption.

Verified artifacts: timestamped .zip.enc files in ~/vw-backups (e.g. vaultwarden-2026-09-24-1749.zip.enc). This is exactly the "encrypt before it leaves the box, key stays on the box" pattern used for production secrets.

Other operational hygiene

  • Container restart policies — restart: always / unless-stopped across the compose fleet (including Prometheus, added after a Pi reboot exposed a missing policy); Docker's healthchecks (several containers report healthy). The same lesson applied to the portfolio site server: it started as a bare background process and died on a reboot, so it was promoted to a systemd user service (portfolio-server, Restart=always) — verified by kill -9 and watching systemd respawn it.
  • Loopback-only binding for internal helpers (FlareSolverr 127.0.0.1:8191, Valkey, Immich postgres) — smallest reasonable attack surface.
  • Disk health on the 1 TB NVMe via smartmontools; rpi-eeprom-update tracks firmware.
  • Reproducible base — RPi-Imager image (2026-07-28) as the provisioning baseline, so the OS layer can be rebuilt, not just patched.
  • Agent-operable — the Hermes runtime exposes the same metrics/ops surface to tooling (Grafana MCP, terminal), so status checks and routine tasks can be automated or delegated (see local-ai-agents).

Known gaps (honest list)

  • No restic/borg snapshot of the full data set yet (Vaultwarden is the exception); media is by nature re-downloadable, the photo archive is the candidate for offsite replication.
  • Single host = single failure domain; a second Pi/mini-PC as witness/replica is the natural next step (the offsite rsync target already proves the pattern works).
  • Grafana dashboards still to be built on top of the now-live TSDB (datasource is installed; first dashboards are the next task).
